# Archived v1.0 Documentation (Pre-Pivot — Reference Only)

These documents describe the **original v1.0 TrackSense product**: a UHF Gen2
lip-implant race-timing platform built around fixed-gate finish-line readers
(Impinj/LLRP via sllurp, Times-7 antennas) and live in-race sectional timing.

**That product direction has been retired.** TrackSense v2.0 is a HISA compliance
platform built around the existing Jockey Club LF microchip and commodity
handheld scanners — not UHF implants or fixed-gate readers. See the top-level
`PROJECT_DESCRIPTION.md`, `ROADMAP.md`, and `docs/PIVOT_NOTES.md` for the current
product and the reasoning behind the pivot.

These files are kept **for historical reference only**. They are **not** accurate
for v2.0 and should not be used to guide current development.
